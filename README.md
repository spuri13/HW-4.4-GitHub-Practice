# HW 4.4: GitHub Practice
This is a repo that provides both a QMD and PDF file that highlights analysis and visualizations for different scenarios including data from the Busiest 
Airport Passenger Traffic (2020-2025) and Monte Carlo Numerical Integration. Furthermore, it compares and contrasts the difference between informed 
and uninformed AI prompting through Claude to a given Calcium data set.  

## Dataset Sources
-Busiest Airport Passenger Data: sourced from Wikipedia
-Calcium: provided by STAT 184 Course Instructor

## Project Plan 
Upload the finished QMD and PDF files to Github repo and practice GitHub Commands including branching, set, and pull requests
